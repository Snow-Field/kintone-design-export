# 確定した前提条件

| ID | 項目 | 内容 | 確認日 | 影響 |
| --- | --- | --- | --- | --- |
| P-01 | 出力に必要な機能 | 設計書に見出し行の固定とオートフィルタが必要 | 2026-08-21 | 両方に対応する Excel ライブラリが必須（D-01） |
| P-02 | 不要な機能 | 条件付き書式と画像の埋め込みは不要 | 2026-08-21 | これらの有無はライブラリ選定の基準にしない |
| P-03 | 配色 | 現状のシアン系から変更する。最終的な色は利用者が後日自分で調整する | 2026-08-21 | 色定義を1か所に集約し、差し替えだけで反映される構造にする（D-07） |
| P-04 | 可視性 | 配色は文字が読める水準を担保する | 2026-08-21 | 見出しの背景色と文字色のコントラスト比を WCAG AA 以上で維持する |
| P-05 | xlsx-js-style の制約 | 見出し行の固定・条件付き書式・画像に非対応（SheetJS Pro の機能）。最終公開は 2022-05 | 2026-08-21 | P-01 を満たせないため継続利用できない |
| P-06 | write-excel-file の制約 | オートフィルタに非対応（SheetOptions に該当プロパティが無い）。見出し固定・条件付き書式・画像には対応 | 2026-08-21 | P-01 を満たせないため採用できない |
| P-07 | ExcelJS の対応状況 | 見出し固定・オートフィルタ・条件付き書式・画像のすべてに対応。ブラウザ向けビルドを同梱（925kB, minified） | 2026-08-21 | P-01 を満たす唯一の選択肢（D-01） |
| P-08 | ゲストスペース | ゲストスペースのアプリは画面URLが `/k/guest/{スペースID}/{アプリID}/`、REST API のパスが `/k/guest/{スペースID}/v1/...` になる | 2026-08-21 | アプリIDの抽出とAPIパスの切り替えが必要 |
