# ドキュメント

kintone アプリの設計情報を Excel 出力する Chrome 拡張機能のドキュメント。
機能概要とインストール手順はリポジトリ直下の `README.md`、実装上の規約は `CLAUDE.md` を参照。

## 索引

| ファイル | 扱う範囲 |
| --- | --- |
| `status.md` | 現在の進捗・リスク |
| `constraints.md` | 確定した前提条件（P-xx） |
| `open-questions.md` | 未確定事項（Q-xx） |
| `specs/excel-layout.md` | 出力される Excel の構成・体裁 |
| `ai/decisions/` | 判断の記録（D-xx） |

## ID凡例

| 接頭辞 | 意味 | 定義元 |
| --- | --- | --- |
| `Q` | Question・未確定 | `open-questions.md` |
| `P` | Premise・確定した前提 | `constraints.md` |
| `D` | Decision・判断 | `ai/decisions/` |
